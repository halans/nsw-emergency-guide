# Third-party sources and software

## Emergency information

Resource data cites the government agency or service provider responsible for the information. This is original concise directory wording with links, not a mirror of the full government/service websites. No government logos, crests or endorsement claims are used. Linked publishers retain rights in their material; check their own terms before republishing it beyond this directory.

## Blume and dependencies

Blume is MIT-licensed. The source project declares and locks upstream packages; normal installation obtains their licence files in `node_modules`. The optional offline archive contains the same public npm package tarballs, whose packages include their upstream notices. It does not purport to relicense those packages. Consult each dependency's package metadata and bundled licence before redistributing a modified dependency bundle.

## Fonts

Self-hosted Inter Latin 400/500/600/700 WOFF2 files were taken from the pinned `@fontsource/inter` package. Its SIL Open Font License is included at `fonts/OFL.txt`.

## Browser verification support

The optional offline archive carries Playwright's Chromium headless shell and FFmpeg downloads for the tested Linux x64 environment, including the notices shipped in those directories. Chromium and its components have their own licences. These files are testing support, not deployed website assets.
